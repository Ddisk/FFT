1. 波形は sin・cos の足し算で表せる

フーリエ解析の出発点。複雑な周期波形も、周波数の違う正弦・余弦成分に分けて考えられます。

100 Hz の基本波
＋
200 Hz の成分
合成すると形が変わる
x(t)=A₁sin(2πf₁t)+B₁cos(2πf₁t)+A₂sin(2πf₂t)+…
FFTは逆向きに考える：「この複雑な波形には、100 Hzがどれだけ？ 200 Hzがどれだけ？」を求める。

2. なぜ「掛けて、全部足す」と周波数が分かる？

同じ周波数のsin・cosとの積和から成分を取り出します。異なるDFTビンの基底は、N点全体で正負が打ち消し合います。

同じ周波数

Σ x[n]・sin(2πfn/fₛ) → 大きく残る

図は同位相のsin同士。位相が90°違うとsinとの積和は0でも、cosとの積和に成分が残る。

違う周波数

Σ x[n]・sin(2πf'n/fₛ) → ほぼ打ち消す

例：100 Hz × 130 Hz。正負が交互に現れ、平均は小さくなる。

重要：「完全に0になる」は理想条件の話。観測区間に整数周期が入らない、周波数がFFTビンに一致しない、途中で切る、などの場合は成分が周辺に漏れる（スペクトルリーケージ）。そのため窓関数を使うことがあります。

3. DFTの式は「cos と sin を掛けて足す」をまとめたもの

難しそうに見える複素指数も、オイラーの公式で分ければ中身は同じです。

X[k] = Σn=0N−1 x[n] e−j2πkn/N

オイラーの公式

e−jθ = cosθ − j sinθ

これをDFT式へ代入する。

すると

X[k] = Σx[n]cos(2πkn/N)
− j Σx[n]sin(2πkn/N)

cos方向とsin方向を同時に求めている。

n
時間側のサンプル番号
k
周波数側のビン番号
N
FFTに使うサンプル数
|X[k]| = √(Re² + Im²) はDFT係数の大きさ。窓なし・ビン一致の正弦波の片側振幅は通常 2|X[k]|/N（DC・偶数Nのナイキストは |X[k]|/N）。位相は atan2(Im, Re)、j²=−1。

4-1. DFTとFFTの違い

FFTは「別の変換」ではありません。DFTと同じ結果を、対称性・周期性などを利用して高速に求める計算法です。

DFT

定義どおりに計算

各kについて、N個のデータとの積和を求める。

概ね O(N²)

Nが増えると計算量が急増。

FFT

DFTを効率よく計算

同じ計算を使い回し、分割してまとめる。

代表的に O(N log N)

2の累乗は高速化しやすいが、現代のFFTは他の長さにも対応できる。

違うのは計算の仕方
FFT点数を必ず1024・2048・4096にする必要はありません。ただし高速化しやすい長さがあり、2の累乗は代表例です。

4-2. FFTは、どの計算を使い回す？

代表的なradix-2 FFT：データを偶数番・奇数番に分け、小さなDFTの答えを再利用します。

① N点を2つのN/2点へ

E[k]：x[0], x[2], x[4]… のDFT
O[k]：x[1], x[3], x[5]… のDFT

WNk = e−j2πk/N

② 1つの積から2つの答え

X[k] = E[k] + WNkO[k]
X[k+N/2] = E[k] − WNkO[k]

k=0,…,N/2−1。同じ積を足す・引くに使う。

N → N/2 → N/4 → … と分割し、下から結合する。N=8なら3段、N=1024なら10段。各段にはN/2個の「バタフライ」（上の加減算の組）があります。

省くのは情報ではなく、重複する計算。数学的には同じDFTであり、実装による丸め誤差はあり得ます。

5. サンプリング数は「何Hzまで」「何Hz刻みで」で決める

必要なのはサンプリング周波数 fₛ とサンプル数 N の両方です。

① 最高周波数

fmax < fₛ/2

どこまで見たいかで fₛ を決める。

② 周波数の目盛り

Δf = fₛ/N

FFTビン間隔 Δf から N を決める。

③ 記録時間

T=N/fₛ
Δf=1/T

細かく見るほど長く測る。

例：1000 Hzまで見たい、FFTの目盛りを1 Hz以下にしたい

fₛ = 2560 Hz

ナイキスト = 1280 Hz

→
N = 4096 点

記録時間 = 1.6 s

→
Δf = 0.625 Hz

6. なぜ「2倍より速く」サンプリングする必要がある？

ここでは0 Hzから最高周波数までの信号を扱います。任意の位相の正弦波を区別するには fₛ>2fmax。ちょうど2倍では、位相によって情報を失います。

100 Hzを100 Hzで取ると…

同じ位相ばかりを測ると、100 Hzで振動していても全サンプルが0になることがある。

t = 0, 10, 20… ms → 0, 0, 0…

100 Hzを200 Hzで取ると…

1周期あたり2点。ただし正弦波がちょうどゼロ交差に重なる位相では、依然として情報を失い得る。

fₛ/2 = 100 Hz は限界点
結論：理論上の基準はナイキスト。実際の測定ではアンチエイリアシングフィルタの遷移帯域や波形再現性もあるため、2倍ぎりぎりより余裕を取る。
fmax < fₛ / 2　⇔　fₛ > 2 fmax

8. 「FFT後半の折り返し」とエイリアシングは別物

実数データのDFTは正負周波数が共役対称。標準配列の後半は、通常の±fₛ/2の範囲では負周波数として読みます。

エイリアシング

測定前・サンプリング時の問題

本物の1200 Hz を fₛ=1000 Hzで取ると、サンプル列は 200 Hz と区別できなくなる。

1200 → 200 Hz

原因：ナイキストを超える成分を標本化した。

DFT配列の後半

FFT結果の並び方

+200 Hz成分の相手として −200 Hz が存在し、raw配列では後半側に入る。

−200 Hz ↔ k=N−200/Δf

0～fₛの周期的な軸では800 Hzの位置。主値区間では−200 Hzと読む。

例：fₛ=1000 Hz、N=10（Δf=100 Hz）

配列k0123456789
正しい周波数0+100+200+300+400−500*−400−300−200−100

* 偶数Nのナイキストビンは +fₛ/2 と −fₛ/2 が同一サンプル列になる特殊点。rFFTでは通常 +fₛ/2 として扱う。

通常の実数信号の振幅スペクトル：負周波数側は冗長なので、0～fₛ/2の片側スペクトルを表示する。

10. 実際のFFTで気をつける4点

数式が正しくても、測定条件でスペクトルの見え方は変わります。

① アンチエイリアシング

ADC前のローパスフィルタで fₛ/2 より上の成分を十分に減衰させる。範囲外成分は「消える」のではなく、低周波へ化ける。

② 窓関数

観測区間の端が不連続だとスペクトルリーケージが出る。Hannなどで端を滑らかにするが、振幅・分解能への影響もある。

③ ビン間隔と分解能

実測点数M、FFT点数Nなら T=M/fₛ、Δf=fₛ/N。ゼロ追加でNだけ増やすと目盛りは細かくなるが、近い2成分を分離する能力は上がらない。

④ 片側振幅

実数信号で両側スペクトルから片側へまとめる場合、窓なし・ビン一致なら2|X[k]|/N。DCと偶数Nのナイキストは|X[k]|/N。奇数Nはナイキストビンなし。窓使用時は振幅補正が必要。

測定条件の決め方

見たい最高周波数fmax
→
fₛを決める>2fmax＋余裕
→
観測時間を決める分離能力と窓を考慮
→
Nを決めるN=fₛT

まとめ：混同しやすいところだけ最後に整理

FFTの計算原理

元データに各周波数のsin・cosを掛け、足し合わせる。DFTの複素指数表現はそのまとめ書き。

FFTとは

DFTと同じ答えを高速に求めるアルゴリズム。変換そのものが別物ではない。

サンプリング

fmax < fₛ/2。ゼロ追加なしのビン間隔は Δf=fₛ/N=1/T。細かく見たいなら長く測る。

エイリアシング

範囲外の周波数が低周波へ化ける。fₛ=1000 Hzなら 1200→200 Hz。fₛ=2000なら800 Hz。

FFT後半

実数信号では負周波数。raw配列の「800の位置」は +800 Hzではなく、fₛ=1000なら −200 Hz と解釈する。

2次成分

本当に200 Hz成分が波形に含まれるときの高調波。FFTの負周波数対称性やエイリアスとは別。

一番大事：「測定範囲外が低周波へ化ける＝エイリアシング」と、「FFT配列後半に負周波数が並ぶ＝共役対称」は分けて考える。
